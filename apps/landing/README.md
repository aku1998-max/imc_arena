# Math Challenge landing page

The site is `index.html` plus `privacy.html` and `support.html` (the stores require both URLs). `index.html` is self-contained: the mascot and logo images are embedded, and the
only external request is Google Fonts. Upload it to any static host as the site's `index.html`.

Not deployed from this repository. Hosting options:

- Netlify Drop (https://app.netlify.com/drop): drag this folder in; you get a public URL in seconds.
- GitHub Pages, Cloudflare Pages or Vercel: point the site at `apps/landing`.
- An existing site (for example the Math Challenge website): upload `index.html` to a page such as `/app`.

The price and plan contents on the page are marketing copy; keep them in step with the app's
billing once payments exist.
